# GlintWin v0.4.1 — 内存优化与验证

本版包含 v0.4 的稳定定位、每日词汇收集箱和单文件分发，并进一步优化词典常驻内存。每日采集仍默认关闭，配置与词库不变。

## 改动
- 内存词条改为紧凑值类型，只保存拼音与最终展示释义；源 JSON 的全部释义保持不变。逐条解析时跳过不会展示的后续释义，不创建完整原始词条对象图。
- 精确查询直接返回预处理结果，避免每次查询重复拆分、正则清理和拼接。
- 每日采集关闭且未打开每日页面时，不打开 SQLite、不启动数据库写入线程；首次启用采集或查看历史时按需初始化。初始化不在键盘回调临界区内执行。

## 可重复基准
同一台机器、同一121564条基础词典、Release构建，优化前后各3个独立进程。MemoryBench会在测量常驻托管数据前执行GC；下表为中位数，不能直接当作整款应用的任务管理器降幅。

| 指标 | v0.4.0 | v0.4.1 |
|---|---:|---:|
| 词典常驻托管内存 | 35.50 MiB | 23.72 MiB |
| 加载累计分配 | 65.99 MiB | 64.12 MiB |
| 独立基准进程私有内存 | 64.25 MiB | 48.95 MiB |
| 一次性词典加载时间 | 264 ms | 297 ms |
| 精确查词10000次额外分配（固定测试词） | 4240000字节 | 0字节 |

常驻词典减少11.78 MiB（约33.2%）；代价是本次测量的一次性加载增加约33ms，后续查词无需重复格式化。
全量拼音+释义摘要前后均为 `0A7191623E420979C3F342AFE65B8ECA9487ECB465BED9B64D36FACAA75A5186`。

## 验证
DictionaryTest10、DailyTest16、PositionTest9、ConfigTest6、ParserTest22、UiTest16，共79项检查通过。覆盖释义规则、空值、属性顺序、词包覆盖、分词、拼音纠错、零分配查询、数据库延迟初始化、历史审核入库、五页渲染及既有功能。
发布包仍为Windows x64自包含单文件，内置.NET运行时与默认词典；中文OCR依赖Windows系统能力。独立包自检见[运行说明](RELEASE-0.4.md)。未以单次新进程内存快照代替相同运行时长的整应用压力测试。
