# GlintWin v0.4.3

修复系统托盘左键点击无响应：NotifyIcon 原先只绑定右键菜单，现在左键点击会在 WPF UI 线程打开控制台；已存在的隐藏窗口会显示，最小化窗口会恢复，普通和最大化窗口保留当前状态，重复点击复用同一窗口。

8项真实NotifyIcon事件与窗口生命周期回归验证左/右键区分、最小化/隐藏恢复、重复打开、最大化状态保留、关闭释放及右键菜单重建；旧版在左键打开检查失败，修复后全部通过。另有17项既有界面回归与独立单文件包自检。测试通过子类隔离App启动，不注册键盘钩子、不启动用户采集，使用独立临时用户目录。

本版仍为Windows x64自包含单文件，词库、每日记录与配置沿用原用户目录。点击关闭控制台后程序继续驻留托盘；退出程序请使用托盘或通用设置中的退出入口。
