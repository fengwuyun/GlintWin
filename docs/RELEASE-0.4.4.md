# GlintWin v0.4.4

- 控制台支持深色／浅色即时切换：侧栏快捷切换或通用设置选择，自动保存；主题切换保留当前表单输入、筛选和悬浮条外观设置。
- 每日词汇统一更名为“词汇采集”。输入、下拉框、日期与日历、多选菜单、表格选中态按主题统一。日期、排序、状态即时筛选，搜索220ms防抖；离开页面使旧请求失效，避免旧查询回写。
- 状态筛选支持多选，多个状态按“或”组合，待核对可与其他状态组合；全部取消等于全部状态。导出使用相同日期、搜索与多选状态条件。
- 总览采用运行状态卡片、词头/词包/个人新增指标、词库构成条与快捷入口；托盘暂停后总览同步显示暂停。
- 中文候选末尾图标被OCR读成@、标点或残留序号时清理后查词与采集；保留词中数字、B12与C++等技术后缀。历史导出清理词条尾部噪声，不批量改写原始历史。
- 自定义词库可搜索词条、拼音、释义；CSV导入同名词使用新翻译覆盖，导入文件内重复行以后者为准，点“保存并重载”生效；修复引号、逗号、多条释义CSV往返。

验证：OCR真实噪声回归、采集与历史导出、多状态并集与分页计数、CSV覆盖与往返、自定义词库搜索、即时筛选、主题持久化与日历弹出、深浅主题五页渲染、托盘生命周期与单文件包自检。
