# 产品需求文档（PRD）— GlintWin

> 版本 1.0 ｜ 2026-11 ｜ 状态：P2 已交付，P3 规划中

## 1. 产品定位

**GlintWin** 是一款 Windows 桌面常驻小工具：用户用中文输入法打字时，在候选词旁边实时显示英文释义——
「输入中文，顺手看见英文」。不替换输入法、不打断心流、全离线。

一句话价值主张：**把每一次中文输入变成一次微型的英语接触（micro-exposure），零额外动作。**

对标产品：macOS 上的 Glint（输入中文顺手看见英文）。Windows 平台目前无同类成熟产品，GlintWin 填补该空白。

## 2. 目标用户与场景

| 用户画像 | 核心诉求 | 使用场景 |
|---|---|---|
| 英语学习者（大学生/职场新人） | 词汇量 4000-8000，"认识但反应慢" | 日常聊天/写邮件时反复接触高频词的英文 |
| 涉外工作者（程序员/外贸/运营） | 中英混杂环境，想要"保持英语语感" | IM 沟通、文档写作、邮件回复 |
| 家长/教师 | 给孩子创造沉浸式语言环境 | 家庭电脑全局开启，打字即学习 |

核心场景：**不是背单词，而是"被动遇见"**——用户查过 10 次的"立即"，在每天 200 次候选词曝光中自然巩固。

## 3. 功能需求

### P0（已交付 ✅）
- F1 搜狗输入法候选词英文释义实时悬浮条
- F2 悬浮条外观自适应输入法皮肤（配色/字号采样）
- F3 全离线词典（CC-CEDICT 12.1 万条）+ 拼音交叉验证纠错
- F4 托盘常驻：暂停/恢复/退出；开机自启（快捷方式）

### P1（已交付 ✅）
- F5 防闪烁管线（像素哈希去重、主题平滑、首显两帧确认、失败保持）
- F6 悬浮条永远位于候选行下方（多屏/DPI 边界处理）
- F7 鼠标穿透、绝不抢焦点

### P2（本次交付 ✅）
- F8 **微软拼音支持**：光标锚定 OCR 通道 + 键盘拼音追踪信号 + 拼音交叉验证防误报

### P3（规划中）
- F9 跟随"当前选中候选"（翻页/数字键选择时释义跟随）
- F10 词汇本：长按/热键收藏生词，导出 Anki/CSV
- F11 双向模式：打英文时显示中文释义（ECDICT）
- F12 设置界面（字号/偏移/主题/黑名单/自启开关）
- F13 更多输入法：双拼、五笔（OCR 路线天然兼容，需验证）、讯飞/百度

### 非功能需求
| 项 | 指标 | 现状 |
|---|---|---|
| 端到端延迟 | 候选变化→释义更新 ≤150ms | ✅ 60–120ms |
| 静态 CPU | <1% | ✅ 趋近 0（哈希去重+限频） |
| 隐私 | 全离线、不读正文、按键不存储 | ✅（源码可审计） |
| 稳定性 | 任何异常不影响输入法 | ✅ 异常隔离 |
| 安装 | 单文件免安装 | ✅ 173MB 自包含 exe |

## 4. 交互原则（产品红线）

1. **绝不抢焦点**：悬浮条 NOACTIVATE+穿透，用户打字永远不受干扰。
2. **绝不翻到候选上方**：释义永远在候选行下方。
3. **宁缺勿错**：识别不确定就不显示（错误释义比没有释义伤害大）。
4. **隐私最小化**：键盘钩子只记录字母序列用于组词判断，不存储不上传；屏幕只截候选区/光标条带。

## 5. 成功指标（建议）

- 北极星：日均"释义曝光次数"（=组词次数×命中率）
- 次级：7 日留存（常驻类工具看周活）、误报率（用户手动关闭次数）、词典命中率
- P3 词汇本启用后：周收藏词数、复习转化率
