# 商业文档 — GlintWin

> 产品价值 / 市场潜力 / 风险 / 商业方向 ｜ 2026-11

## 1. 产品价值

### 1.1 用户价值
- **零动作学习**：传统背单词需要"打开 App→输入→复习"三步；GlintWin 把学习压缩进用户每天
  必然发生的 200-500 次打字行为里，边际成本为零。
- **场景即记忆**：候选词释义出现在"正在表达"的语境里（用户刚打出"立刻"，马上看到
  immediately）——语境化曝光的记忆效率远高于孤立词卡。
- **无打扰**：不抢焦点、鼠标穿透、100ms 内消失——工具的存在感被刻意压到最低，长期使用无负担。

### 1.2 为什么现在做（Why Now）
1. macOS 已有 Glint 验证了该品类的需求与付费意愿（垂类小工具订阅 $3-5/月已跑通）。
2. Windows 端 **没有同类产品**——中文用户体量远大于 macOS，空白明显。
3. Win11 的输入法候选窗已彻底封闭（DirectComposition/无 UIA），技术门槛把多数模仿者挡在门外；
   GlintWin 的"窗口锚定 + 光标锚定 OCR + 键盘拼音追踪"组合方案有实质壁垒。

### 1.3 数据佐证（间接）
- iOS 端"中英输入法-打字学英语"等 App 已上架并进入教育榜（App Store 可查）；
- CC-CEDICT 社区 20 年持续维护，说明"中英词典数据+输入场景"有长期需求。

## 2. 市场与竞争

### 2.1 市场规模（TAM/SAM/SOM 估算）
- TAM：中国 Windows 桌面英语学习/辅助用户 ~1.5 亿（PC 端英语学习工具+涉外办公人群）。
- SAM：输入法场景重度用户（每日打字 >1000 字）~3000 万。
- SOM（首年）：垂类社区（V2EX/少数派/知乎学习板块）+ 输入法用户群精准投放，可触达 10-30 万安装。

### 2.2 竞争格局
| 竞品 | 形态 | 差异 |
|---|---|---|
| 有道词典/欧路划词 | 划词翻译 | 需要主动选中查询，非"输入即得" |
| 搜狗/微软输入法内置 | 英文联想/中英混输 | 只联想英文候选，不解释中文词义 |
| macOS Glint | 同款理念 | 仅 macOS |
| 背单词 App（墨墨/Anki） | 主动学习 | 与"输入场景曝光"互补而非竞争 |

**护城河**：输入法候选窗逆向知识（搜狗/微软双通道）、皮肤自适应取色、防闪烁工程细节、
全离线隐私定位——每一项都不难，组合起来是 3-6 个月的追赶成本。

## 3. 商业模式建议

### 3.1 推荐路径：**免费核心 + 订阅 Pro**（先开源核心引流，双版本运营）
| 层 | 内容 | 定价 |
|---|---|---|
| Free（开源） | 双输入法基础释义、单词典、单悬浮条 | ¥0 |
| Pro（闭源增值） | 词汇本+Anki 导出、多词典（ECDICT/柯林斯例句）、跟随选中候选、云同步、双语双向模式 | ¥8/月 或 ¥68 买断 |

### 3.2 备选/叠加模式
1. **买断制**（¥30-68）：垂类工具用户对买断接受度高，适合独立开发者起步（参考 Glint、iShot）。
2. **教育 B2B**：向培训机构/学校授权"打字即学习"教室版（按坐席年费）——词汇曝光数据对教学方有价值。
3. **词库内容生态**：考研/雅思/托福词库包按证售卖（内容型收入，边际成本零）。
4. **不推荐**：广告（与"无打扰"产品气质冲突，伤害留存）。

## 4. 风险与对策

| 风险 | 等级 | 说明 | 对策 |
|---|---|---|---|
| **输入法兼容性失效** | 高 | 搜狗/微软升级可能改变候选窗形态（本项目已历一次：Win11 DComp 化） | 类名/参数配置化热调；双通道冗余；发布前自动化 E2E 回归 |
| **隐私合规与信任** | 高 | 键盘钩子天然敏感；国内监管（个保法）+ 杀软误报 | 钩子最小化（仅字母/即用即弃）、源码开源可审计、白名单申请、隐私政策明示 |
| **杀软误报** | 中 | LL 钩子+截屏行为易被启发式拦截 | 代码签名证书（EV 造价高，先 OV）；提交主流杀软白名单 |
| **被输入法官方内置** | 中 | 搜狗/微软若做同功能则失去独立性 | 差异化：官方做"联想英文"，本产品做"中文词义+学习闭环（词汇本/复习）"；保持跨输入法中立 |
| **市场规模天花板** | 中 | 垂类工具用户盘有限 | 见 §5 商业方向：向学习闭环与多语言扩展打开天花板 |
| **CC-CEDICT 许可** | 低 | CC-BY-SA 传染性 | 词典数据独立文件+署名，不影响代码授权选择 |
| **单点维护** | 低 | 独立开发者带宽 | 模块化架构+自动化回归（已建），核心链路文档化 |

## 5. 未来商业方向（Roadmap → 商业化）

### 近期（3-6 月）：验证与获客
1. 免费开源版上架 GitHub + 少数派/V2EX/知乎发布，积累种子用户与口碑。
2. 数据埋点（本地统计+用户自愿上报）：曝光量、命中率、误报率——为定价与迭代提供依据。
3. 词汇本 + Anki 导出（Pro 分水岭功能）：从"工具"升级为"学习闭环"，打开付费意愿。

### 中期（6-12 月）：学习闭环 + 平台扩展
4. **复习系统**：词汇本 → 间隔重复（SRS）推送，把"曝光"升级为"掌握"——教育类产品的核心付费点。
5. 多输入法覆盖（双拼/五笔/讯飞）+ Win10 兼容 → 覆盖面翻倍。
6. 多语言扩展：日/韩语释义（Windows OCR 原生支持，词典换数据即可）——日语学习者市场付费意愿更强。

### 远期（12 月+）：平台化
7. **输入法厂商合作/收购可能性**：搜狗（腾讯）/讯飞有动机收购或集成该能力。
8. 企业版：涉外团队"统一语言环境"部署（集中管理词库/黑名单）。
9. 数据产品（合规前提下）：匿名聚合"中文高频词-英文释义"需求图谱，向内容方/教育方输出。

## 6. 总结

GlintWin 是一个**技术壁垒清晰、隐私定位差异化、场景刚需**的垂类工具：短期能以极低成本获取
精准种子用户，中期靠"曝光→词汇本→复习"的学习闭环支撑订阅，长期具备被输入法大厂集成/收购
的战略价值。主要风险集中在平台依赖（输入法升级）与钩子隐私信任，均有明确的工程与合规对策。
